## 1. 项目背景与目标

湖南文理学院此前缺少官方 LaTeX Beamer 毕业答辩/课程汇报模板。本项目参考多个成熟高校
Beamer 模板，将优点有机结合，并注入湖南文理学院视觉识别（VIS）元素，产出一套开箱即用
的模板。交付物：

1. `template/huasbeamer.sty` —— 模板主题样式文件（单文件加载，注释化可调）；
2. `template/HUAS-Beamer.tex` —— 中文版演示文档（暖色调，毕业答辩典型场景）；
3. `template/HUAS-Beamer-EN.tex` —— 英文版演示文档（暖色调，国际汇报场景）；
4. `template/HUAS-Beamer-Blue.tex` / `HUAS-Beamer-Blue-EN.tex` —— 冷色调（蓝白）中英双版；
5. 构建脚本（Makefile / makebeamer.bat / .latexmkrc）与全套文档。

## 2. 参考模板调研

| 模板 | 来源 | 借鉴之处 |
| --- | --- | --- |
| **thubeamer**（清华大学） | `examples/thubeamer-main` | 版式骨架（smoothbars 导航、双行页脚）、节前目录页、封面/封底范式 |
| **NJIT**（南京工程学院） | `examples/NJIT_LaTeX_Template-main` | 单样式文件轻量结构、校徽主题色、**目录高亮规则**（当前节小节展开、其余隐藏） |
| **redus**（厦门大学） | `examples/Xiamen University-Red` | 演示文档内容组织、底部导航控件 |
| **HNU-Beamer-Template**（湖南大学） | `examples/HNU-Beamer-Template` | **封面色带布局 + 左上角校徽 + 底部英文校名**、导师命令、表格宏、Makefile |
| **WHU-Beamer**（武汉大学） | `examples/WHU-Beamer` | 工程组织、文档结构、.gitignore |
| **SCU-Beamer-Theme**（四川大学） | `examples/SCU-Beamer-Theme` | latexmk 工程化配置、分平台字体方案、Times 系数学 |
| **SJTUBeamer**（上海交通大学） | `examples/SJTUBeamer` | 节页两行式结构（编号+标题）、水平章节导航、professionalfonts 字体方案 |

**有机结合思路**：thubeamer 版式骨架 + NJIT 轻量分发与目录规则 + redus 内容范式 +
HNU 封面色带布局 + SJTU 节页结构与学术字体；全部配置注释化，降低使用门槛。

上述路径属于开发阶段的本地调研材料。`examples/`、`research/`、`issues/` 被 `.gitignore` 排除，
不会随仓库克隆；正常使用只需 `template/` 中的正式素材。

## 3. 视觉设计系统（依据 research/ 素材）

### 3.1 色彩（Python/Pillow 像素采样定稿）

| 素材 | 采样色 | 用途（暖色调） |
| --- | --- | --- |
| 校徽 `HUAS-School_badge` | `#CC3433` | 主色 `huasred` |
| 校旗 `HUAS-School_flag` | `#EB3D00` | 强调色 `huasorange` |
| `reference_3` 底色 | `#B34F21` | 参考；深端取 `#8F2420`（`huasdeep`，保证白字对比度） |
| 建筑线稿 | `#E06742` | 装饰色 `huascoral` |
| 校旗金 | 亮金黄 | 点缀 `huasgold`（`#F5B301`，加深保证浅底可读） |
| — | — | 页面底色 `huasbg` `#FDFAF3`（暖米白） |

冷色调（`[blue]`）：`#2B5FA8` 学术蓝 / `#16406E` 藏蓝 / `#2E86C1` 亮蓝 /
`#6FA8DC` 浅蓝 / `#9DC3E6` 淡蓝银 / `#EFF4FA` 浅蓝白 / `#FFFFFF` 纯白底。

### 3.2 图形元素

- **校徽** `HUAS-School_badge-transparent-imagegen-v2.png`：封面左上角；
- **校标** `HUAS-Logo_nobadge.png`（书法无徽版）：封面中央；含徽彩色版备用；
- **建筑线稿**：图书馆（封面背景水印、节页白色版）、校门（目录页水印、致谢页白色版）；
- **校训**「博学 弘文 明理 求真」：保留定义，默认不在页面显示（可按需加回）。

### 3.3 字体

- 西文/数字：Times 衬线体系（Times New Roman / TeX Gyre Termes）+ newtxmath 数学；
- 中文正文：黑体（FandolHei，参考论文正文）；节页标题保持宋体衬线；中文可用楷体点缀。
- 中文模式采用 `ctex[fontset=none]` 后显式设置字体；英文模式由 xeCJK 提供中文文献字形。
  正文斜体对应 FandolKai，数学运算符使用 `ntxtlf` 的 OT1 字体，避免系统字体编码不匹配。

## 4. 技术方案

### 4.1 文件组织

```
HUAS-Beamer/
├─ README.md / LICENSE / .gitignore
├─ template/                  # 正式模板包
│  ├─ huasbeamer.sty          # 主题样式（★注释化可调★）
│  ├─ HUAS-Beamer.tex         # 中文暖
│  ├─ HUAS-Beamer-EN.tex      # 英文暖
│  ├─ HUAS-Beamer-Blue.tex    # 中文冷
│  ├─ HUAS-Beamer-Blue-EN.tex # 英文冷
│  ├─ reference.bib / figures/
│  └─ Makefile / makebeamer.bat / .latexmkrc
├─ docs/                      # 入门教程、开发计划、自定义说明、静态预览图
├─ examples/                  # 可选本地调研参考模板（Git 忽略）
└─ research/                  # 可选本地原始素材（Git 忽略）
```

### 4.2 编译链

四版均为 XeLaTeX + BibTeX；在 `template/` 下运行 `latexmk 文件.tex`，
由 `.latexmkrc` 选择引擎并完成重复编译。Windows PowerShell 可运行 `.\makebeamer.bat`，
Linux/macOS 可运行 `make`；Overleaf 选 XeLaTeX。

批处理在结束时清理辅助文件并暂停，不适合作为需要保留日志的验证入口。
Makefile 按已列依赖的时间戳决定是否构建，图片替换后可用 `make -B`。
编辑器 `.vscode/` 被 Git 忽略，构建配方示例保存在[项目主页](../README.md#vs-code-配置与排错)，
不依赖开发电脑的全局 VS Code 设置。

### 4.3 主题实现要点

1. 单文件 `huasbeamer.sty`（NJIT 轻量结构），内部按 color/inner/outer 逻辑分区注释；
2. 双色系 `\ifhuas@blue` 分支整体切换（`[blue]` 选项）；
3. smoothbars 顶栏 + 双行页脚（汇报人+时间/单位 · 标题/按键+页码）；
4. 封面（HNU 布局）：色带 + 左上角校徽 + 中央信息 + 底部单位/日期 + 色带英文校名；
5. 节页（SJTU 结构）：编号行 + 节标题 + 水平章节导航，渐变背景 + 白色线稿；
6. 目录页：校门水印、中文数字编号、NJIT 高亮规则；
7. `[en]` 英文模式不加载 ctex，保留 xeCJK；`\supervisor` / `\reportdate` / `\huastableheader` 等实用宏。
8. 当前 `\huassetlogo` 和 `\huassetbg` 接入封面；`\huassetbadge`、`\huassetdeco` 仅定义，
   尚未接入版式。文档按实际生效范围说明，不将预留接口描述为已完成能力。

## 6. 验收标准

1. 四个 `HUAS-Beamer*.tex` 均以 XeLaTeX 编译通过，零 error、零 Overfull；
2. 封面含色带、校徽、校标、标题信息、单位/日期与底部英文校名，配色符合 HUAS VIS；
3. 目录页（中文数字编号、校门水印、NJIT 高亮规则）与节页（编号+标题+章节导航）完整；
4. 页脚（汇报人+汇报时间/单位 · 标题/翻页按键+页码）完整；
5. 常用元素（列表/公式/表格/图/代码/引用/参考文献/致谢）均有可复用范例；
6. 用户仅需修改 `\title` 等六个命令即可复用；
7. 全部可调整项有注释与文档双重说明。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 素材为位图/带白底 | 封面不美观 | 透明 PNG 优先；深/浅底分别提供 `-white`/原版线稿 |
| 中文编译字体缺失 | 编译失败 | 使用 Fandol；系统字体需修改显式字体命令及局部字体族，不能只切 `fontset` |
| 黑体行高导致目录溢出 | 版式失衡 | 目录条目字号收档（\small/\footnotesize），已验证零溢出 |
| PDF 被占用无法写入 | 编译中断 | 关闭阅读器重编（FAQ 有说明） |
| 英文文献中包含中文 | 缺字或方框 | `[en]` 通过 xeCJK 配置中文字体；保留中文资料时检查字形，选项不翻译文献 |

## 9. 开发规范（自 v1.8 起执行）

1. **命名**：文档与代码文件名不使用 `demo` 等临时性称谓，采用 `HUAS-Beamer` 体系命名
   （`HUAS-Beamer` / `-EN` / `-Blue` / `-Blue-EN`）。
2. **修改范围**：仅修改需求明确指定的内容；对需求之外觉得值得调整的地方**不擅自修改**，
   在该轮开发结束时以「建议事项」形式提出，经确认后再实施。
3. **命名对照**（历史记录保留旧名）：

   | 现名 | 旧名 |
   | --- | --- |
   | `HUAS-Beamer.tex` | `demo-cn.tex` |
