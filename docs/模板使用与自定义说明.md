# HUAS-Beamer 自定义说明文档

> 本文档列出模板中**所有可调整项**：内容填写、主题选项、颜色、尺寸、图片、文字、字体、
> 行距、表格宏等，参数值与 `huasbeamer.sty`（v1.8）完全一致。
> 样式文件内亦有 `★调色★ / ★尺寸★ / ★图片★ / ★文字★ / ★字号★ / ★行距★ / ★字体★ / ★位置★`
> 就地注释；修改时搜索文中给出的**命令名/颜色名/关键字**即可定位。

**文档命名对照**（v1.8 起）：`HUAS-Beamer.tex`（中文暖）/ `HUAS-Beamer-EN.tex`（英文暖）/
`HUAS-Beamer-Blue.tex`（中文冷）/ `HUAS-Beamer-Blue-EN.tex`（英文冷）；
下文以 `HUAS-Beamer*.tex` 泛指四者。

## 1. 内容填写（必改项）

### 1.1 封面与页脚信息

在 `HUAS-Beamer*.tex` 导言区修改：

```latex
\title[页脚短标题]{封面主标题}        % 方括号=页脚第二行左侧短标题；花括号=封面大标题
\subtitle{封面副标题}                 % 可省略整行
\author[页脚短作者]{答辩人：XXX}      % 方括号=页脚第一行左侧
\supervisor{指导教师：XXX}            % 封面导师行，可省略整行
\institute[页脚短单位]{\small 湖南文理学院·XX学院}
\date{\small 2025 年 6 月}
\reportdate{2025 年 6 月 10 日}       % 可选：固定页脚汇报时间（默认编译日期 \today）
```

| 命令 | 显示位置 | 说明 |
| --- | --- | --- |
| `\title[短]{全}` | 封面大标题；页脚第二行左侧 | 不写方括号则页脚显示完整标题 |
| `\subtitle{...}` | 封面主标题下方 | 可整行删除 |
| `\author[短]{全}` | 封面中央；页脚第一行左侧 + 汇报时间之前 | |
| `\supervisor{...}` | 封面作者行下方 | 可整行删除 |
| `\institute[短]{全}` | **封面底部**（色带上方）；页脚第一行右侧 | |
| `\date{...}` | **封面底部**（单位下方） | 任意文字或 `\today` |
| `\reportdate{...}` | 页脚第一行（汇报人之后） | 默认 `\today`（=编译 PDF 日期） |

> **页脚两行**：第一行 = 汇报人 + 汇报时间（左）· 单位（右）；
> 第二行 = 标题（左）· 翻页按键 + 页码（右）。

### 1.2 正文结构

```latex
\section{节标题}          % 自动插入「渐变节页 + 目录页」
\subsection{小节标题}     % 配合 [subsectiontoc] 选项可自动出目录页
\begin{frame}{帧标题} ... \end{frame}   % 一页幻灯片；含 lstlisting 需加 [fragile]
```

## 2. 主题选项

```latex
\usepackage{huasbeamer}                 % 默认：中文暖色调 + 节前目录页 + 翻页按键
\usepackage[blue]{huasbeamer}           % 冷色调（蓝白，页面底色纯白）
\usepackage[en]{huasbeamer}             % 英文模式（不加载 ctex，全英文编译）
\usepackage[notoc]{huasbeamer}          % 关闭节前自动「渐变节页+目录页」
\usepackage[subsectiontoc]{huasbeamer}  % 每个小节前也插入目录页
\usepackage[nonav]{huasbeamer}          % 关闭底部翻页按键
```

选项可组合，例如 `\usepackage[blue,en]{huasbeamer}`（= HUAS-Beamer-Blue-EN 的配置）。

## 3. 颜色自定义

### 3.1 色值定义（`huasbeamer.sty` 搜索 `\definecolor`）

**默认暖色调（校徽红系）：**

| 颜色名 | 默认值 | 用途 |
| --- | --- | --- |
| `huasred` | `#CC3433` 校徽红 | 主色：结构色、列表符、块标题底、页脚第二行、目录编号 |
| `huasdeep` | `#8F2420` 深红 | 页脚第一行、渐变深端、标题字、封面色带 |
| `huasorange` | `#EB3D00` 校旗橙红 | 渐变亮端、alert 块、顶栏小节色 |
| `huascoral` | `#E06742` 珊瑚 | 图注、目录小三角 |
| `huasgold` | `#F5B301` 校旗金 | 备用点缀 |
| `huascream` | `#F7F2EC` 米白 | 浅色装饰（备用） |
| `huasbg` | `#FDFAF3` 暖米白 | **所有页面底色**（更白→`#FDFCF9`，更黄→`#FBF5EA`） |

**`[blue]` 冷色调（蓝白系）：** 同名颜色整体替换——`huasred` `#2B5FA8` 学术蓝、
`huasdeep` `#16406E` 藏蓝、`huasorange` `#2E86C1` 亮蓝、`huascoral` `#6FA8DC` 浅蓝、
`huasgold` `#9DC3E6` 淡蓝银、`huascream` `#EFF4FA` 浅蓝白、`huasbg` **`#FFFFFF` 纯白**。

改法示例（把暖版页面底色调得更黄）：

```latex
\definecolor{huasbg}{HTML}{FAF2DE}
```

### 3.2 常见改色需求对照

| 想改什么 | 改哪里 |
| --- | --- |
| 所有页面底色 | `\definecolor{huasbg}{HTML}{...}` |
| 封面顶部/底部色带 | 搜 `0.40cm`（顶部主条 `huasdeep` + 副条 `huasred!75`）、`0.48cm`（底部 `huasdeep`） |
| 底部色带英文校名颜色 | 搜 `\huas@nameen`（`text=white`） |
| 页脚第一行底色 | `\setbeamercolor{firstbottomline}{fg=white,bg=huasdeep}` |
| 页脚第二行底色 | `\setbeamercolor{secondbottomline}{fg=white,bg=huasred}` |
| 帧标题字色/底色 | `\setbeamercolor{frametitle}{fg=huasdeep,bg=huasbg}` |
| 节页渐变两端色 | 搜 `section page` 中 `\shade[left color=huasdeep,right color=huasorange]` |
| 致谢页渐变 | `HUAS-Beamer*.tex` 最后一帧同样的 `\shade[...]` |
| 块环境配色 | `block title` / `block body` 等（浅底=色 8% + huasbg 92%） |
| 翻页按键线条色 | 搜 `\huas@navsymbols`（`white`） |
| 目录高亮/灰色 | 搜 `section in toc shaded`（`black!35`）；高亮用 `huasred` |
| 顶栏渐变 | `section in head/foot`（huasdeep）与 `subsection in head/foot`（huasorange） |
| 正文字色 | `\setbeamercolor{normal text}{fg=black!85,bg=huasbg}` |

## 4. 尺寸与间距

### 4.1 行距与列表间距（搜索 `行距与列表间距`）

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 全局行距 | `\linespread{1.08}` | 改大更疏（1.1~1.2）、改小更密（1.0） |
| 列表项间距 | `\itemsep=0.45ex` | itemize/enumerate 项间空隙 |
| 子列表项间距 | `\itemsep=0.2ex` | |
| 表格行高倍率 | `\arraystretch=1.25` | 改大表格行间更疏 |

### 4.2 封面（搜索 `title page`）

> 布局（借鉴 HNU-Beamer-Template）：顶部色带 → 左上角校徽 → 中央（校标/标题/副标题/
> 答辩人/导师）→ 底部（单位 + 日期）→ 底部色带（白色加粗英文校名，中英文版均显示）；
> 背景为图书馆线稿水印。

| 元素 | 默认值 | 改法 |
| --- | --- | --- |
| 顶部色带 | 主条 `huasdeep` 0.40cm + 副条 `huasred!75` 0.08cm | 搜 `0.40cm` |
| 底部色带 | `huasdeep`，高 0.48cm | 搜 `0.48cm` |
| 底部色带英文校名 | `\huas@nameen`，`\small\bfseries` 白字，`anchor=center` 垂直居中于带内 | 搜 `\huas@nameen` |
| **左上角校徽** | `huas-badge-v2.png`，`height=1.35cm`，位置 (1cm, -0.75cm) | 搜 `huas-badge-v2` |
| **单位与日期** | 页面底部（色带上方）`\small` 两行，`yshift=0.75cm` | 搜 `yshift=0.75cm` |
| 背景水印（图书馆线稿） | `width=1.16\paperwidth`，`opacity=0.16`，`yshift=-2.0cm` | 搜 `opacity=0.16` |
| 校标 logo | `huas-logo-nobadge.png`，`width=0.44\paperwidth` | `\huassetlogo{文件名}` |
| 中央块上下留白 | 前后 `\vfill`（自动平衡居中） | |
| 中央各行间距 | `\\[2.2ex]`、`\vskip0.7ex`、`\vskip1.6ex` | |

### 4.3 页脚（搜索 `footline`）

**内容来源**见 §1.1；尺寸参数：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 第一行高度 | `ht=2.4ex,dp=1.05ex` | 汇报人+时间/单位行 |
| 第二行高度 | `ht=2.6ex,dp=1.25ex` | 标题/按键+页码行 |
| 左右内边距 | `leftskip/rightskip=.35cm` | |
| 名字与汇报时间间距 | `\hspace{1.2em}` | |
| 翻页按键与页码间距 | `\hspace{0.6em}` | |
| 页码分隔符 | `\setframeofframes{--}` 可改（默认 `/`） | 如 `3 / 25` |
| 翻页按键 | `\huas@navsymbols`：白色线条三角 ◁ ▷（`\small`，间距 `\hspace{0.35em}`） | `[nonav]` 关闭 |

### 4.4 帧标题（左上角）

| 项 | 默认值 | 改法 |
| --- | --- | --- |
| 字号 | 中文版 `\Large`、英文版 `\large`（均 `\bfseries`） | 搜 `★字号★ 中文版帧标题` |
| 上下留白 | `\vskip1.2ex` / `\vskip0.8ex` | 搜 `frametitle` 模板 |
| 左右内边距 | `leftskip=.45cm` | 同上 |

### 4.5 节标题页（搜索 `section page`）

结构（借鉴 SJTUBeamer）：第一行编号（`第 X 节` / `Section X`）→ 第二行节标题 →
底部水平章节导航（各节横向列出、当前节高亮）；渐变背景 + 白色图书馆线稿。

| 元素 | 默认值 | 改法 |
| --- | --- | --- |
| 编号行 | `\normalsize\bfseries`，白色 80%；中文局部 `\songti` | 搜 `第~\insertsectionnumber~节` |
| 节标题字号 | `\LARGE\bfseries`（中文局部 `\songti` 保持宋体衬线） | `\setbeamerfont{section title}` |
| 章节导航 | `\scriptsize`，`\insertsectionnavigationhorizontal` | 不需要可整行删除 |
| 节页线稿 | `building-library-white.png`，`width=1.04\paperwidth`，`opacity=0.16` | 搜 `section page` |
| 渐变背景 | `huasdeep → huasorange` | 同上 |
| 间距 | `\vskip2.4cm` / `\vskip1.2cm` / `\vskip0.9cm` | 编号上/标题下/导航距底 |

### 4.6 目录页

| 元素 | 默认值 | 改法 |
| --- | --- | --- |
| 背景线稿 | `\tocbackground`：校门线稿 `width=1.1\paperwidth`、`opacity=0.12`、`yshift=-2.6cm` | 搜 `\tocbackground`；删除该行即去掉背景 |
| **编号** | 中文数字「一、二、三、四、」（`\huas@cnnum`）；英文版阿拉伯「1.」 | 搜 `\huas@cnnum` |
| **高亮规则** | 节前目录：当前节及其附属小节高亮、其余节灰显且**不显示其余节的小节**（NJIT 规则 `subsectionstyle=show/show/hide`） | 搜 `subsectionstyle` |
| 灰色 | `black!35` | 搜 `section in toc shaded` |
| 条目字号 | 节/小节 `\small` / `\footnotesize`（防黑体行高溢出） | `\setbeamerfont{section in toc}` |
| 总目录字号 | 导言区局部 `\large`（`\setbeamerfont{section in toc}{size=\large}`） | 见 `HUAS-Beamer*.tex` 目录帧 |
| 目录位置 | 节前目录 `\vskip-1em`；总目录 `\vskip-2em`（更靠上） | 目录帧中改该值 |
| 小节条目符号 | 珊瑚色小三角 ▶、缩进 `leftskip=2.2em` | 搜 `subsection in toc` |

## 7. 字体

**西文与数字（学术标准 Times 衬线体系）：**

- 主字体：`Times New Roman`（Win/Mac 自带），不存在时自动回退 `TeX Gyre Termes`；
- 数学：`newtxmath`（Times 风格）+ `\usefonttheme{professionalfonts}`；
- 全局衬线：`\usefonttheme{serif}`（偏好无衬线可删除此行）；
- 修改入口：搜 `★字体★ 学术标准`。

**中文：**

- 字库默认 **fandol**（TeX Live 自带，跨平台）；
- **内容中文为黑体**（参考《浅谈自读课文的教学》论文正文）：
  `\setCJKmainfont{FandolHei-Regular}[BoldFont=FandolHei-Bold]`（搜 `★字体★ 内容中文`）；
  **节页编号与标题局部 `\songti`** 保持宋体衬线；改回宋体：删除 `\setCJKmainfont` 行；
- Windows 系统字体方案：`\RequirePackage[fontset=windows]{ctex}`，
  黑体行改 `\setCJKmainfont{SimHei}`；
- 帧标题字号中文 `\Large` / 英文 `\large`（§4.4）。

## 8. 表格辅助宏（借鉴 HNU-Beamer）

```latex
\begin{tabular}{lll}
  \huastableheader                       % 整行浅红底（huasred!15）
  \huastableheaderfont 列一 & \huastableheaderfont 列二 & \huastableheaderfont 列三 \\
  \midrule
  ...
\end{tabular}
```

表头底色：搜 `\newcommand{\huastableheader}`；表头字体：`\huastableheaderfont`。
表格行高：`\arraystretch=1.25`（§4.1）。

## 9. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 含代码 `lstlisting` 的页报错 | 该 frame 必须加 `[fragile]` |
| 参考文献显示 `[?]` | `xelatex → bibtex → xelatex → xelatex` 四步编译 |
| 英文版编译中文报错 | 英文文档务必 `\usepackage[en]{huasbeamer}` |
| 封面/目录装饰位置偏移一次 | TikZ `remember picture` 需两轮编译，属正常现象 |
| PDF 被占用无法覆盖编译 | 关闭预览该 PDF 的阅读器后重新编译 |
| Overleaf 使用 | 上传 `template/` 全部内容，编译器选 **XeLaTeX** |
| 节前目录页太多 | `[notoc]` 关闭，需要时手动 `\tableofcontents` |
| 目录条目溢出页脚 | 节前目录字号已收至 `\small`；再溢出可改 `\footnotesize`（§4.6） |

## 10. 速查：一页纸改样式流程

1. 改内容 → `HUAS-Beamer*.tex` 导言区 §1 六个命令；
2. 改颜色 → 搜 `\definecolor`（§3.1）或按 §3.2 对照表定位；
3. 改行距/表格疏密 → 搜 `行距与列表间距`（§4.1）；
4. 改封面 → 搜 `title page`（§4.2：色带/校徽/底部信息/水印）；
5. 改页脚 → 搜 `footline`（§4.3）；
6. 改节页/目录页 → §4.5 / §4.6；
7. 改图片 → §5 素材表与替换命令；
8. 改字体 → §7；
9. 重新 `xelatex` 两遍生效。
