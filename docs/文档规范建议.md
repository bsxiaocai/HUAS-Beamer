# HUAS-Beamer 文档规范建议

> 本文档记录经确认后应长期遵守的版式/文档规范条目，供后续开发与修订对照执行。
> 每条规范注明来源需求与生效位置；未标注「建议」的条目为已实施的强制规范。

## 1. 封面页版式规范（书法艺术字 / 标题 / 底部信息）

**适用范围**：全部四个模板 `HUAS-Beamer.tex` / `HUAS-Beamer-EN.tex` / `HUAS-Beamer-Blue.tex` /
`HUAS-Beamer-Blue-EN.tex`。四者共用 `huasbeamer.sty` 中的 `title page` 封面模板，
修改一处即全模板生效，**不得**在单个 `.tex` 内另行覆盖封面布局。

**生效位置**：`template/huasbeamer.sty` 封面模板（搜索 `title page`）。

### 1.1 规范条目

| 编号 | 规范 | 取值 / 做法 | 源码定位 |
| --- | --- | --- | --- |
| C1 | 书法艺术字与主标题的间隙应保持紧凑（约 1.5 倍行距观感），**不得加大** | `\nointerlineskip` + `\vskip1.2ex`（关闭默认行距后显式控制） | 校标 `\includegraphics` 下方的 `\vskip1.2ex` |
| C2 | 封面中央主体（书法校标 + 标题/副标题/作者/导师行）位置整体偏上 | 顶部 `\vskip-0.5cm plus0.1fill`：负值 −0.5cm 即整体上移量，底部保留 `\vfill` | `\vskip-0.5cm plus0.1fill` 与行尾 `\vfill` |
| C3 | 「湖南文理学院·文学院」与「2025 年 6 月」（即 `\institute` / `\date`）**保持底部位置不变** | 独立锚定于 `current page.south` 上方 `yshift=0.75cm`，不随 C1/C2 的调整移动 | `title page` 内 TikZ 节点 `\node[anchor=south ...] at ([yshift=0.75cm]current page.south)` |

### 1.2 说明

1. **书法艺术字**指封面校标 `figures/huas-logo-nobadge.png`（无徽章书法版）中的
   「湖南文理学院」艺术字，通过 `\huassetlogo{}` 可整体替换图片，但 C1 的间隙约束不变。
2. C1 与 C2 联动生效：C1 缩小间隙使标题向校标靠拢，C2 进一步把「校标 + 标题信息」
   整体上移；二者只作用于中央主体。C3 的底部单位/日期是独立锚定节点，
   无论主体如何调整都固定在页面底部。
3. C2 的上移用负向 `\vskip`（−0.5cm）显式控制，后接少量弹性（`plus0.1fill`），
   以便副标题/导师行增删时主体仍保持偏上且不与底部信息重叠；
   需要继续上移或回调时只改该负值。
4. 若未来更换校标图片（含自带留白变化），以视觉效果为准复核 C1 数值，
   规范值 `\vskip1.2ex` 为上限参考，换图后只减不增。

### 1.3 验收标准

1. 四个模板封面：书法艺术字与主标题间距明显紧凑（约 1.5 倍行距观感），无明显大空隙；
2. 封面中央主体整体位于版面中线偏上，视觉重心不塌底；
3. 「湖南文理学院·文学院」「2025 年 6 月」（英文版为对应单位与 `June 2025`）
   仍紧贴底部色带上沿，位置与改版前一致；
4. 四个模板均以 XeLaTeX 编译通过，零 error、零 Overfull。

## 2. 节标题页版式规范（编号行 / 节标题 / 章节导航）

**适用范围**：同 §1 的四个模板，共用 `huasbeamer.sty` 中的 `section page` 模板，
修改一处即全模板生效。

**生效位置**：`template/huasbeamer.sty` 节标题页模板（搜索 `section page`）。

### 2.1 规范条目

| 编号 | 规范 | 取值 / 做法 | 源码定位 |
| --- | --- | --- | --- |
| S1 | 节页**不显示**底部水平章节导航目录行 | 已整体移除 `\insertsectionnavigationhorizontal` 一行 | `section page` 模板内注释「水平章节导航已按需求移除」 |
| S2 | 「第 X 节 / Section X」编号行 + 节标题**整体位于版面中线偏上** | 上方留白 `\vskip2.0cm` < 下方留白 `\vskip2.6cm`（不对称留白实现偏上） | `section page` 模板两处 `\vskip` |

### 2.2 说明

1. S1：节页只保留渐变背景 + 图书馆线稿 + 编号行 + 节标题的两行式结构，不加回任何
   横向导航/目录元素。
2. S2：上下留白不对称使编号+标题整体偏上；微调位置时只改这两个 `\vskip`，
   且保持「下方留白 > 上方留白」。

### 2.3 验收标准

1. 四个模板节页均无底部章节导航目录行；
2. 编号行与节标题整体略偏上，不与图书馆线稿主体冲突、不顶出渐变区上沿；
3. 四个模板均以 XeLaTeX 编译通过，零 error、零 Overfull。

## 3. 目录页版式规范（节条目圆圈 / 字号）

**适用范围**：同 §1 的四个模板，共用 `huasbeamer.sty` 中的目录条目模板
（总目录页与节前/小节前目录页同一套条目样式）。

**生效位置**：`template/huasbeamer.sty` 目录页模板（搜索 `目录页`）。

### 3.1 规范条目

| 编号 | 规范 | 取值 / 做法 | 源码定位 |
| --- | --- | --- | --- |
| T1 | 目录节条目为**立体圆圈**（TikZ `ball` 渲染），**圆圈内包汉字数字**「一、二…」（英文版为阿拉伯数字），圆圈后留白再接节标题 | 圆圈 `minimum size=2.8ex`，圈后 `\hspace{1.4ex}` | `\setbeamertemplate{section in toc}` 内 `\tikz ... \node[ball color=huasred ...]` |
| T2 | 圆圈颜色取**相近色系**，与整体视觉一致 | `ball color=huasred`（主色；暖/冷主题自动切换为红/蓝系） | 同上 `\node` 选项 |
| T3 | 目录页字体**对齐清华大学 thubeamer 模板目录大小** | 节条目 `\Large` 加粗；小节条目 `\normalsize`（保持层级） | `\setbeamerfont{section in toc}` / `subsection in toc` |

### 3.2 说明

1. T1 的圆圈、留白、数字字号均为独立可调参数（`minimum size` / `\hspace` / `font`）；
   换字号时圆圈直径与圈内数字字号需同步微调，保证汉字四周略有余量。
2. T2 随主题色系自动切换：`[blue]` 冷色调下圆圈为蓝系，不需单独修改。
3. 节前/小节前目录页的高亮规则（当前节红球高亮、其余淡化，小节三角符号）
   保持既有 NJIT 规则不变；条目增多时优先微调条目间距 `\vskip0.8ex` 防溢出。

### 3.3 验收标准

1. 四个模板目录页节条目均为「立体圆圈 + 汉字数字（英文版阿拉伯数字）+ 留白 + 节标题」；
2. 圆圈颜色与整体色系相近、协调（暖红/冷蓝随主题）；
3. 目录字号与 thubeamer 目录观感相仿（节条目大字），总目录与节前目录页均无溢出；
4. 四个模板均以 XeLaTeX 编译通过，零 error、零 Overfull。
