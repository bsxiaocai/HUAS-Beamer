# Phase 3 视觉模式与配置接口总结（2026-09-28）

## 本阶段依据与方案

重读开发总纲、许可提示和 Phase 0／1／2、许可阶段总结，并阅读代码审查提示中的检查要点。用户本轮明确要求下一阶段开发，因此推进总纲 Phase 3。对照本地 SJTUBeamer 的旧选项与模块分工、Metropolis 的 PGF 键值配置与章节钩子机制，使用已有 PGF 提供的 `pgfkeys`，没有新增宏包或复制参考项目实现。

## 完成内容

- 建立导言区接口 `\HUASsetup{...}`，支持 `style=academic/warm`、`logo=true/false`、`footer=standard/minimal/none`、`sectionpage=true/false`、`language=zh/en` 和 `faculty={文字}`。默认配置保持原有浅色、标准页脚、关闭 Logo 与自动章节页的行为；后续配置覆盖先前指定项。
- 配置状态集中在 `theme/huas-config.tex`；color theme 管理模式色彩，inner theme 管理完整页面与自动章节页，outer theme 在渲染时读取页脚模式。旧主题选项继续使用相同状态，避免设置接口出现两套互相冲突的值。
- 提供 `\HUASmaketitle`、`\HUASsectionframe`、`\HUASclosingframe` 完整页面命令，局部处理背景和页码。Warm 模式使用暖红与白字，正文始终保留浅色；建筑图在浅色辅助区显示，避免原图橙色线条与暖红背景对比不足。
- 用 `\HUASsetbuilding{路径}` 接入用户新增的两张透明 PNG。第一张用于完整页面的辅助建筑区，第二张用于双栏示例；缺失图像仍可回退到原创示意线稿。未改写图像内容，图像本身继续留在忽略的 `assets/research/`。
- English 配置切换固定校名标签与致谢文字；用户内容仍由用户决定语言。院系文字显示在章节／结束页和标准页脚；简洁页脚只显示页码。
- 更新 README、素材说明及 NOTICE 的源码范围与新素材状态。

## 实际验证与审查

每组行为改动后均运行 XeLaTeX。测试文件和输出集中在被忽略的 `build/phase3/`。

| 场景 | 结果 |
| --- | --- |
| Academic 默认示例＋新素材＋自动章节页 | 五页 16:9，标题、章节、两页正文和结束页正常 |
| Warm 示例＋新素材 | 连续两遍成功，五页；暖色完整页面与浅色正文无颜色泄漏 |
| English＋两行长英文标题＋minimal 页脚＋关闭自动章节页 | 连续两遍成功，四页；标题换行正常，正文只显示页码 |
| 独立目录仅复制可分发源码，没有 research 素材，使用 Warm | 连续两遍成功，五页；校名文字、示意线稿和图片占位正常 |
| 旧选项、重复 setup、none 页脚、logo=false、手动章节页及缺失建筑路径 | 连续两遍成功，四页；仅有预期的缺失图像警告 |
| 无效 `style=invalid` | PGF 给出明确配置错误并在 halt-on-error 下停止，不默默使用错误值 |

常规场景的最终日志无 error、warning、overfull 或 underfull。检查全部 Academic／Warm 示例页面，以及英文长标题、素材回退和兼容性场景的渲染图。对照 Git diff 和审查提示，未发现阻塞性问题。检查时将暖色状态的应用限制在完整页面命令内部，防止旧 `\titlepage` 调用出现白底白字；并限制任意 Logo 的最大宽高。

## 尚未完成好与限制

- 两张新建筑 PNG 在小尺寸投影下细节较弱，仍带少量提取残留；本轮没有修图。若后续需要更清晰版本，应由有权使用素材的人提供更干净的透明图或矢量源。
- Warm 模式目前只控制封面、章节与结束页；没有提供深色正文模式。固定页面文字支持 zh/en，但不自动翻译正文、日期、机构或校训；英文模式不臆造校训翻译。
- `faculty` 当前是简短文字配置，没有院系标识组合或多行长页脚适配。仅验证了两行英文标题和 16:9；极长标题、密集正文、其他比例仍需按真实用途检查。
- 本机 Windows + TeX Live 2025 验证完成，跨平台与 Overleaf 未实测。图片提取不等于取得再分发许可，两个 PNG 仍不纳入 Git，也未将仓库公开或推送。

## 下一阶段注意

进入 Phase 4 前继续阅读 `docs/development/DEVELOPMENT_PROMPT.md`、许可提示及 `docs/` 各阶段总结。基于真实学术内容逐项增加必要组件，不为组件数量制造环境；每次只实现一项并编译、检查日志和视觉结果。保持颜色通过 color theme 管理、图片路径通过资产接口传入；不要在正文加入整页建筑背景。若使用自定义 `\AtBeginSection`，应明确它会替换自动章节页钩子。公开素材与发行包装留待明确授权和后续工程化阶段。
