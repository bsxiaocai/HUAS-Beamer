# Phase 6 自主微调接口与模板说明总结（2026-09-28）

## 阅读与本阶段范围

重读开发总纲、许可要求、审查要点及 Phase 0～5、许可阶段总结。查看本地 Metropolis 的外层参数、页眉页脚和标题机制，SJTUBeamer 的标题框选项与默认布局，并核对 TeX Live 随附 Beamer 的正文边距、PGF 的值键机制。借鉴机制，未复制第三方代码。

用户明确要求为每份模板给出具体操作说明、解释各处效果与修改方式，并在源码中增加必要注释。因此本阶段继续完善 Phase 5 的使用文档，命名为 Phase 6；总纲本身没有新增编号阶段。不改图、不补绘建筑、不增加新的内容组件。

## 完成内容

- 新增导言区接口 `\HUASsetlayout{...}`，34 项尺寸键集中在 `theme/huas-layout.tex`：正文边距、页眉／正文标题栏／页脚宽高、标题栏内距、短线尺寸、封面与章节留白、辅助区栏宽、校徽／建筑上限、引文和重点框内距。默认值与 Phase 5 一致；没有新增依赖。
- 外层、内层、素材与内容模块在实际渲染位置读取对应参数，保留 em／ex 与当前字体、textwidth／linewidth 与当前环境的关系。尺寸接口只用于导言区，重复调用只覆盖指定项，正文边距通过 Beamer 的原生 setbeamersize 设置。
- `docs/customization.md` 说明全部尺寸默认值、cm／mm／pt／em／ex 的差别，区分页眉与标题栏、ht 与 dp、内边距与总高度；包含字体角色、颜色令牌、图表、代码、参考文献与固定文字的位置及修改方法。
- 四份独立逐页指南位于 `docs/templates/main.md`、`academic.md`、`seminar.md`、`cool.md`。分别覆盖 5／10／9／16 张物理页和 2／6／5／11 张正文计数页，给出封面信息、配置项、每页内容修改、双栏／图片／表格的具体尺寸和可用代码片段。
- 四份示例的导言区有中文说明和可取消注释的调参片段；双栏比例、图片占位尺寸、表格行高、fragile 与 keypoint 等关键位置有就地注释。共享主题注释解释参数读取、比例上限、基线校正与颜色刷新。
- README 与 examples/README 建立文档入口，NOTICE 增加新源码范围；LPPL 正文、已有图片和字体文件未更改。

## 实际验证与修正

| 场景 | 结果 |
| --- | --- |
| 四份默认示例 | 连续两遍 XeLaTeX 成功，5／10／9／16 页，最终日志无 error、warning、overfull、underfull |
| 默认视觉回归 | 以同一 Poppler 900px 渲染与 Phase 5 页面逐像素比较，除另行比较的 Warm 封面外全部相同；Warm 封面用同一 1400px 预览比较亦完全相同，共覆盖 40 页 |
| Cool 尺寸微调 | 16 页两遍成功；非对称边距、15.5cm 栏宽、4.3mm 页眉、4.8mm 页脚、更大标题框内距、辅助区与引文内距均生效，无日志异常 |
| Warm 尺寸微调 | 9 页两遍成功；13.6cm 正文宽、3cm 短线、2pt 线厚、章节间距、校徽与结束页间距正常，无日志异常 |
| 原生内容块与图注选项 | 按手册的三种 block begin 默认模板选项改 colsep 为 1ex，图注前后改为 4pt／2pt，Cool 16 页两遍成功，无日志异常 |
| 独立目录无 research 素材 | 复制全部必要主题／示例源码，Cool 16 页两遍成功；建筑区留空、校徽跳过、正文图使用占位，无日志异常 |
| 拼错键名 headline heigth | PGF 明确报未知键；halt-on-error 下退出码为 1，无静默接受 |

渲染核对 Cool 整套页面、调参后的栏宽／标题块、Warm 封面及缺图页。缩窄标题栏并使用不对称边距时，Beamer 标题容器会影响色块的水平位置；据实际结果补充了说明，未假定三栏缩窄后自动对齐。校徽宽度上限的文档也明确区分整页 textwidth 与辅助区 minipage 内的局部 textwidth。

测试命令最初将 PowerShell 参数 `-output-directory=.` 直接写为裸参数，XeLaTeX 错把点当输入文件；加引号后成功。现有 build 脚本已经给输出目录参数加引号，不需要改动。所有测试源与产物都在被忽略的 build/phase6 内。

## 未完成好与限制

- 尺寸接口没有自动纠正负数、超过页面的宽高或导致内容拥挤的组合；只验证文档列出的合理修改场景。大幅调整后的排版仍需作者编译确认。
- 封面保留 vfill 弹性布局，没有固定 y 坐标；标题行数、字号、图片尺寸会共同影响位置。把某个顶部留白当成最终物理坐标会产生误解，文档已明确。
- 页眉页脚的 ex 在框建立处求值，不能随意换算为固定 mm；想精确宽高应使用绝对单位。标题栏高度随行数变化，不提供会裁掉多行标题的固定高度开关。
- 三组细小基线／水平间距仍保留就地常量，没有为每个微小对齐值新增公共键；已给出具体文件、数值和方向说明。原生 block 的内部间距仍按 Beamer default 模板管理。
- 说明是 Markdown 操作手册，没有另行生成一份 PDF 手册；跨平台字体与非 16:9 布局继续未实测。此前的代码高亮、自动参考文献和素材分发问题没有扩大到本轮处理。

## 下一阶段注意

继续重读开发总纲及阶段总结，以真实自主微调反馈判断是否需要增加参数。新增尺寸必须同步更新共享手册、对应模板说明和渲染验证；保留默认视觉回归，避免修改注释或接口时意外改变版式。非对称边距与缩窄色块不能只靠理论计算，要检查 PDF 实际位置。建筑只使用现有素材，图片颜色与线条不由布局接口生成。公开分发和推送仍按用户明确授权进行。
