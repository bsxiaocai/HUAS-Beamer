# 参考代码

Phase 0 下载了以下参考项目，保存在 `examples/references/`，仅供本地研究，不纳入 HUAS-Beamer 的 Git 提交：

- [SJTUBeamer](https://github.com/sjtug/SJTUBeamer)：参考 `ctexbeamer`、16:9、XeLaTeX 的最小用法及 Beamer 主题入口；下载版本 `72a76138446137c1090070ba0cf66cbe56b3bd80`，Apache-2.0。
- [ZJU-Beamer-Template](https://github.com/qychen2001/ZJU-Beamer-Template)：参考轻量项目结构和 XeLaTeX 编译说明；下载版本 `a276635341cee0e5b31c5ac004a1999fb3c9785b`。发布或复用其代码前需单独核对许可。

当前主题没有复制这些项目的代码。若需重新下载：

```sh
git clone --depth 1 https://github.com/sjtug/SJTUBeamer.git examples/references/SJTUBeamer
git clone --depth 1 https://github.com/qychen2001/ZJU-Beamer-Template.git examples/references/ZJU-Beamer-Template
```
